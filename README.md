# is95cdmaone
Collection of resources (mostly reference component implementations and code) useful for developing an IS-95 cdmaOne implementation

##### Various Matlab implementations of IS-95 CDMA

Decoder only
https://github.com/brianodermatt/MIMO-CDMA

IS-95 baseband simulation for 1 data channel of 9.6 KBps rate, over AWGN, both mod/demod with Viterbi encoding/decoding
https://www.mathworks.com/matlabcentral/fileexchange/5460-is-95-simulation-code

IS-95 Simulation with Metric Information
https://www.mathworks.com/matlabcentral/fileexchange/9719-is-95

simple simulation of an IS-95A cellular network
https://github.com/timcardenuto/IS95A-simulator



##### A set of FEC libaries including Viterbi Decoders
https://github.com/ka9q/libfec


##### GNU Radio CDMA out of tree blocks

https://github.com/anastas/gr-cdma
